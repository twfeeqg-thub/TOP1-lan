# README_LOGIC.md — components/forms (النماذج الموحّدة)

## المنطق البشري (Human Logic)

نظام النماذج الموحّدة (Phase 3) يجعل إنشاء القطاعات/المشاريع/الإعلانات تجربة تعريفية خالصة:

- **DynamicField**: يعرض حقل `FieldSchema` واحداً (نص، نص طويل، قائمة، رقم، منطقي، تاريخ، رابط، كلمة مرور، JSON) بمدخلات زجاجية وأهداف لمس 44×44.
- **DynamicForm**: معالج متعدد الخطوات يقرأ `FormSchema` — تحقق لكل خطوة، تحويل نهائي عبر `transform`، ثم POST إلى `endpoint`. عند النجاح يُبطل كيانات React Query المعرّفة في `invalidateKeys` ويُظهر شاشة نجاح.
- **MasterCreateWizard**: يضم `FormSchema` داخل `GlassModal` ويحقن خيارات القوائم الحية (مثل قطاعات مشروع PWA) عبر `fieldOptions` دون كسر الطابع التعريفي.

## القواعد المطلقة
1. كل نموذج يبقى تعريفياً في `lib/forms/*` — لا منطق عرض داخل المخططات.
2. جميع الأزرار والحقول ≥ 44×44 بكسل.
3. لا يُرسل النموذج إلا بعد تجاوز تحقق الخطوة الحالية بالكامل.
