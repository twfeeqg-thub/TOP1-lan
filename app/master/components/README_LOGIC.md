# README_LOGIC.md — app/master/components (مكونات لوحة الماستر)

## المنطق البشري (Human Logic)

مكونات واجهة لوحة الماستر المشتركة:

- **nav-items.tsx**: مصفوفة روابط الشريط الجانبي — تشمل الآن `forms` (أيقونة `FilePlus2`، متاحة لـ `super_admin` و `master`) لفتح معالجات الإنشاء الموحّدة. أي صفحة إدارة جديدة تُضاف هنا فقط ولا في كل مكوّن فرعي.
- **stats-card.tsx**: بطاقة مؤشر KPI زجاجية تستهلك `KpiStat[]` من `lib/stats` (مؤشرات حقيقية) وتعرض الرقم والنسبة والتغير.
- **offline-sync-pump.tsx**: مضخّة مزامنة الطابور — تستنزف `core.master_outbox` عبر `markApplied` وتعيد المحاولة بآلية تأجيل.
- **sidebar-logo.tsx**: شعار الهوية الجانبية للوحة.

## القواعد المطلقة
1. إضافة صفحة إدارة جديدة = سطر واحد في `nav-items.tsx` (التسمية العربية + الأيقونة + الدور).
2. لا تُحوّل الأرقام لعرافة أو "N/A" في بطاقات KPI — المؤشرات حقيقية من القاعدة.
3. أي زر تفاعلي ≥ 44×44 بكسل.
