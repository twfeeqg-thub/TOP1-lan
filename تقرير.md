## 2. دالة جلب البيانات مع Fallback

### `lib/get-sector-data.ts`
- دالة `getSectorData(slug)` — تبحث في `sectorsMock` عن الـ slug النشط، ثم ترجع بيانات `sectorFullData[sector.id]`.
- تعتمد كلياً على mock data كـ Fallback مؤقت (لا تحتاج قاعدة بيانات).

### حالات الـ Fallback

| السيناريو | السلوك |
|-----------|--------|
| slug موجود ونشط | بيانات كاملة من `sectorFullData` |
| slug غير موجود أو غير نشط | `notFound()` → 404 |
| `sectorFullData` لا يحتوي على الـ id | `notFound()` → 404 |

## 5. تحديث محرك الإعلانات — Kill Switch + isPremiumUser

### `components/ad-renderer.tsx` — التغييرات

| الميزة | الوصف |
|--------|-------|
| **Kill Switch** | `useEffect` لجلب `/api/master/ads/kill-switch` عند تحميل المكون. إذا `json.data.active === true` → لا يُعرض أي إعلان (return null). في حالة فشل الطلب، يُسمح بعرض الإعلانات (fail-open). |
| **isPremiumUser** | Prop جديدة (افتراضي `false`). إذا `true` → لا يُعرض أي إعلان لهذا المستخدم. |
| **ترتيب الـ Hooks** | تم إعادة ترتيب الكود بحيث كل الـ Hooks (useState, useEffect, useRef, useCallback) تُستدعى قبل أي early return لضمان compliance مع قواعد React. |

### مسار تدفق إخفاء الإعلانات
```
isPremiumUser === true → return null (مستخدم مميز لا يرى إعلانات)
killSwitchLoaded === false → return null (في انتظار نتيجة Kill Switch)
killSwitchActive === true → return null (الإعلانات موقوفة عاماً)
filteredAds.length === 0 → return null (لا توجد إعلانات لهذا الموضع)
```

## 8. خلاصة معمارية

```
المستخدم → /[sector_slug] (Server Component)
                │
                ├── getSectorData(slug)
                │     ├── sectorsMock.find(slug) ← slug → id
                │     └── sectorFullData[id]     ← SectorData كاملة
                │
                ├── if (!data) → notFound() ← 404
                │
                └── تفرش 7 مكونات + 3 نقاط إعلان
                      ├── DynamicHero          (Server)
                      ├── Ad_Renderer (top)     (Client, Kill Switch-aware)
                      ├── DynamicProjects      (Server)
                      ├── Ad_Renderer (middle)  (Client, Kill Switch-aware)
                      ├── DynamicAbout         (Server)
                      ├── DynamicTestimonials  (Client)
                      ├── DynamicFAQ           (Client)
                      ├── DynamicPartners      (Server)
                      ├── Ad_Renderer (bottom)  (Client, Kill Switch-aware)
                      └── DynamicLegalFooter   (Server)
```
