# README_LOGIC.md — lib/forms (مخططات النماذج الموحّدة)

## المنطق البشري (Human Logic)

مخططات النماذج التعريفية (Phase 3) تصف كل معالج إنشاء ببيانات خالصة دون أي منطق عرض:

- **types.ts**: أساس النظام — `FieldSchema` (نوع/اسم/تسمية/تحقق/خيارات) و `WizardStep` و `FormSchema` (خطوات + endpoint + تحويل + مفاتيح إبطال الكاش).
- **sector-schema.ts**: مخطط إنشاء القطاع، ويعيد **تصدير `SectorFormWrapper` مباشرة** من وحدة قطاع الماستر — أي أن السوبر أدمن يعدّل أقسام القطاع السبعة التفصيلية بنفس تجربة أدمن القطاع تماماً، بلا تكرار أي منطق.
- **project-schema.ts**: مخطط مشروع PWA — `sector_name` قائمة تُحقن خياراتها الحية من `/api/master/sectors` وقت التشغيل.
- **ad-schema.ts**: مخطط حملة إعلانية يطابق عقد `/api/master/ads` (POST) عبر `transform` يبني غلاف `ad_config`.

## القواعد المطلقة
1. المخططات تعريفية صرفة — لا استيراد pg ولا أي منطق خادم.
2. `sector-schema.ts` يعيد استخدام `SectorFormWrapper` — لا نسخة مكررة من تبويات القطاع.
3. القوائم الحية تُحقن عبر `fieldOptions` ولا تُثبّت داخل المخطط.
