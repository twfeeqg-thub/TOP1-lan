# README_LOGIC.md — الجذر (Root)

## المنطق البشري (Human Logic)

هذه المنصة (ذكاء سهل) هي منصة سحابية سيادية متعددة القطاعات. فلسفة التصميم الأساسية تقوم على:
- **فصل المحتوى المطلق**: لا يوجد محتوى ثابت في القوالب. كل النصوص، الصور، الإعدادات، التهيئات، وحتى سمات الألوان تُخزَّن كـ JSONB في قاعدة البيانات (Supabase/PostgreSQL). القوالب مجرد "حاويات عرض" (Renderers) خاوية تقرأ JSONB وتصدّره.
- **العمل دون اتصال هو الأساس (Offline-First)**: المنصة تستخدم IndexedDB عبر Dexie.js لتخزين المشاريع والإعلانات محلياً. في البيئات ضعيفة الاتصال، يتم الاعتماد على النسخ المخبأة (Cache-first) مع بيانات احتياطية (Fallback data) مدمجة في الكود لضمان استمرارية الخدمة.
- **هندسة طبقتين للمصادقة**: Access Token (قصير العمر 15 دقيقة، HttpOnly=false) و Refresh Token (طويل العمر 7 أيام، HttpOnly=true) لدعم الجلسات السيادية.
- **منطق القيادة من الأعلى**: المنصة تدير قطاعات متعددة (تعليم، صحة، عقارات، تجارة...) من خلال لوحة تحكم مركزية واحدة (Master).

## الهيكل الآلي (Auto-Structure)

```
/
├── app/
│   ├── [sector_slug]/       ← قالب زجاجي ديناميكي أجوف (يقرأ JSONB)
│   ├── api/auth/            ← مصادقة REST سيادية
│   ├── api/master/          ← API مركزية للوحة القيادة
│   └── master/              ← واجهة القيادة والسيادة
├── components/
│   ├── sector/              ← مكونات عرض القطاعات (تقرأ JSONB)
│   └── ad-renderer.tsx      ← طابور الإعلانات الديناميكي
├── lib/
│   ├── db.ts                ← Dexie.js (IndexedDB) للتخزين المحلي
│   ├── supabase.ts          ← عميل Supabase للمتصفح (Anon Key)
│   ├── supabase-pool.ts     ← pg Pooler (6543) + logAudit للخادم، و poolAdmin (REST/Service Role)
│   └── get-sector-data.ts   ← قراءة full_data من core.sectors (فصل خطأ القاعدة عن انقطاع الشبكة)
├── hooks/
│   └── use-projects.ts      ← React Query + Cache مع Fallback
└── .cursorrules             ← دستور التنفيذ الصارم
```

## القواعد المطلقة
1. لا يجوز كتابة أي نص ثابت في أي قالب عرض. كل المحتوى من JSONB.
2. يجب أن يظل نظام التخزين المحلي (IndexedDB/Dexie.js) قائماً في كل الطبقات.
3. أي إضافة جديدة يجب أن تكون "إضافة" (Add-on) لا تعديل للقائم إلا بإذن صريح.
4. لا تُستخدم البيانات الوهمية (mock) في العرض أو المسارات — تُكتفى بالاحتفاظ بها معطّلة (Conditional Deletion).
